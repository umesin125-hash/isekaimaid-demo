## 🎮 ゲーム概要

ライトノベル『**異世界メイドはまさかの俺⁉︎ 並行世界へのカエリカタ**』の世界観をもとに制作している、**iPhoneのSafariでも遊べる2D横スクロールアクションゲーム**の試作版です。

主人公たちを操作し、異世界の森に現れる魔物を倒しながら先へ進みます。

近接攻撃の**ミリア**、銃による中距離攻撃の**カナト**、魔法による遠距離攻撃の**アリステア**。3人の戦い方を切り替え、魔力量子を溜めて強力な**量子共鳴魔法**を発動しましょう。

本作は、原作小説をゲームという別の形で体験してもらうための**個人制作・開発中のプロトタイプ**です。原作の設定や演出をベースにしつつ、ゲームとしての遊びやすさを優先したアレンジも含まれます。

## 📖 あらすじ

魔力量子が遍在する異世界。

この世界にやってきた**カナト・ルクス**、メイドであり剣士でもある**ミリア・レフス**、そして魔法研究の第一人者**アリステア・ミリオーネ**。

3人の前に立ちはだかるのは、凶暴な魔物たち。

剣、魔導銃、そして魔法。それぞれの得意分野を活かし、森の奥に待ち受ける巨大な魔物へ挑め！

本作を通じて世界観や登場人物に興味を持っていただけたら、ぜひ原作ライトノベルもお楽しみください。

## 👥 操作キャラクター

### ⚔️ ミリア・レフス（Milia Refs）

**戦闘タイプ：近接攻撃／日本刀**

- メイド服をまとった剣士。
- 通常時は日本刀を納刀した状態で携行。
- 攻撃時に抜刀し、素早い斬撃で敵を攻撃。
- 青い斬撃エフェクトは**近接攻撃の演出**であり、飛び道具ではありません。

### 🔫 カナト・ルクス（Kanato Lux）

**戦闘タイプ：中距離攻撃／リボルバー**

- 赤いコートが特徴の主人公。
- シルバーの大型リボルバーを使用。
- 射撃によって離れた敵を攻撃可能。
- キャラクタースプライトのバージョンにより、連続射撃時の銃構え演出が含まれます。

### ✨ アリステア・ミリオーネ（Alistea Milione）

**戦闘タイプ：遠距離魔法／《光の棘》**

- 「永遠の学匠」の称号を持つ魔法研究者。
- 武器を持たず、片手を前に伸ばして魔法を発動。
- 光の棘を射出して遠くの敵を攻撃。
- ミリアの斬撃とは異なり、こちらは**飛び道具**です。

## 🕹️ 操作方法

### 📱 iPhone・スマートフォン（画面内ボタン）

| ボタン | 動作 |
| --- | --- |
| `◀` | 左に移動 |
| `▶` | 右に移動 |
| `JUMP` | ジャンプ |
| `攻撃` | 選択中のキャラクターで通常攻撃 |
| `交代` | ミリア → カナト → アリステアの順にキャラクターを切り替え |
| `共鳴` | MQゲージが100のとき量子共鳴魔法を発動 |

**iPhoneでは画面を横向きにしてプレイしてください。** 縦向きのときは案内画面が表示されます。必要に応じて画面の回転ロックを解除してください。

### ⌨️ PC（キーボード）

| キー | 動作 |
| --- | --- |
| `←` / `A` | 左移動 |
| `→` / `D` | 右移動 |
| `Space` / `↑` / `W` | ジャンプ |
| `J` | 通常攻撃 |

## ⚛️ バトルシステム

### 1. キャラクター交代

3人はそれぞれ攻撃範囲や攻撃方法が異なります。

- 敵に接近できるときは**ミリア**で斬撃。
- 距離を保ちたいときは**カナト**で射撃。
- 離れた敵には**アリステア**の魔法。

状況に応じて戦い方を切り替えましょう。

### 2. HP（体力）

敵の攻撃を受けるとHPが減少します。HPが0になると**GAME OVER**です。

一部の敵を倒すと回復アイテムが出現することがあります。

### 3. MQ（魔力量子ゲージ）

敵に攻撃を当てると**MQゲージ**が増加します。

ゲージが**100**に達したら、`共鳴` ボタン（PCでは `L`）で必殺技を発動できます。

### 4. 量子共鳴魔法 ― TRIPLE RESONANCE

カナト・ミリア・アリステア、**3人の力を合わせた強力な特殊攻撃**です。

- MQゲージ100で発動可能。
- 画面全体に特殊演出が発生。
- 周辺の敵に大きなダメージを与えます。
- 発動後、MQゲージはリセットされます。

### 5. ステージクリア

1. オオカミ型モンスターを突破して右へ進む。
2. 森の奥にいる**巨大クマ型ボス**と戦う。
3. ボスを倒したら、さらに**右端へ移動**する。
4. `STAGE CLEAR!` が表示されればクリアです。

## 🌙 STAGE 01 ― 月夜の森

静かな夜の森林が舞台。大きな月、星空、青い森、草地面をドット絵で表現しています。

**ミッション：巨大熊型魔物を討伐せよ！**

道中のオオカミ型モンスターに注意しながら進み、最奥でボスに挑戦してください。

### 攻略のヒント

- 敵に不用意に接近しすぎないよう、キャラクターを使い分けましょう。
- HPの残量をこまめに確認しましょう。
- MQゲージが100になったら、ボス戦での使用も検討しましょう。
- ボスを倒しただけでは終了しません。**右端まで進んでください。**

## 🎵 BGM・効果音

タイトル画面とステージで異なるBGMを使用しています。

| 表示・操作 | 内容 |
| --- | --- |
| タイトル画面 `♪ BGM ▶` | タイトルBGMの再生開始 |
| `♪ BGM ON / OFF` | BGMの有効・無効を切り替え |
| `SFX ON / OFF` | 効果音の有効・無効を切り替え |

**iPhone Safariでは、ブラウザの制限により、画面を開いただけでは音が鳴らないことがあります。** `PUSH START` やBGMボタンなどをタップして再生を開始してください。

> 本体に音源を内蔵した版では、画像とBGMの別途ダウンロードは不要です。音楽・素材の再利用や再配布については、それぞれの権利者・利用条件をご確認ください。

## 🚀 遊び方

### GitHub Pagesで公開されたゲームを遊ぶ

1. ゲームの公開URLをSafariやPCブラウザで開きます。
2. スマートフォンの場合は**横画面**にします。
3. タイトル画面の `PUSH START` を押します。
4. ステージ開始演出後、画面内ボタンで操作します。
5. ボスを倒し、右端まで進んでクリアを目指します。

### HTMLを直接使う場合

ゲームの配布ファイルが**内蔵版 `index.html`** の場合は、ゲームの画像・BGM・JavaScriptがHTML内に含まれています。

環境によってはローカルファイルからの動作や音声再生に制限があるため、**GitHub PagesなどのHTTPS環境でのプレイを推奨**します。

## 🌐 GitHub Pagesへの公開方法（リポジトリ管理者向け）

GitHubにログインし、公開するリポジトリへ次のファイルを置きます。

```text
リポジトリ名/
├── index.html   # ゲーム本体
└── README.md    # この説明書（GitHubのトップページに表示）
```

1. GitHubのリポジトリを開き、**`index.html` と `README.md` をルート（最上位）に配置**します。
2. `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` を **Deploy from a branch** にします。
4. `Branch` は **main**、フォルダは **/(root)** を選び、保存します。
5. 公開処理が終わったら、表示されたサイトURLにアクセスします。

公開URLの一般的な形式：

```text
https://＜GitHubユーザー名＞.github.io/＜リポジトリ名＞/
```

> GitHub FreeでGitHub Pagesを利用する場合、通常は**公開（Public）リポジトリ**が必要です。リポジトリを公開すると、アップロードした `index.html` や素材も閲覧・取得可能になります。公開してよい内容か事前に確認してください。

### README.mdを変更するには？

GitHubのリポジトリ直下にある `README.md` を編集してコミットすると、リポジトリのトップページに表示される説明が更新されます。**ゲームのコードを変更せずに、説明書だけ更新可能**です。
