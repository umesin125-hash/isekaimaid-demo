## 🎮 ゲーム概要

ライトノベル『**異世界メイドはまさかの俺⁉︎ 並行世界へのカエリカタ**』の世界観をもとに制作している、**iPhoneのSafariでも遊べる2D横スクロールアクションゲーム**の試作版です。

主人公たちを操作し、異世界の森に現れる魔物を倒しながら先へ進みます。

近接攻撃の**ミリア**、銃による中距離攻撃の**カナト**、魔法による遠距離攻撃の**アリステア**。3人の戦い方を切り替え、魔力量子を溜めて強力な**量子共鳴魔法**を発動しましょう。

本作は、原作小説をゲームという別の形で体験してもらうための**個人制作・開発中のプロトタイプ**です。原作の設定や演出をベースにしつつ、ゲームとしての遊びやすさを優先したアレンジも含まれます。

**戦闘タイプ：近接攻撃／日本刀**

- メイド服をまとった剣士。

## ⚛️ バトルシステム

### 1. キャラクター交代

3人はそれぞれ攻撃範囲や攻撃方法が異なります。

- 敵に接近できるときは**ミリア**で斬撃。
- 距離を保ちたいときは**カナト**で射撃。
- 離れた敵には**アリステア**の魔法。

状況に応じて戦い方を切り替えましょう。

### 2. HP（体力）

敵の攻撃を受けるとHPが減少します。HPが0になると**GAME OVER**です。

一部の敵を倒すと回復アイテムが出現することがあります。

### 3. MQ（魔力量子ゲージ）

敵に攻撃を当てると**MQゲージ**が増加します。

ゲージが**100**に達したら、`共鳴` ボタン（PCでは `L`）で必殺技を発動できます。

### 4. 量子共鳴魔法 ― TRIPLE RESONANCE

カナト・ミリア・アリステア、**3人の力を合わせた強力な特殊攻撃**です。

- MQゲージ100で発動可能。
- 画面全体に特殊演出が発生。
- 周辺の敵に大きなダメージを与えます。
- 発動後、MQゲージはリセットされます。

### 5. ミリア専用・残像ダッシュ

通常走行の1.7倍の速度で最大0.7秒間ダッシュします。地上でのみ発動でき、青紫色の残像が通過地点に連続して生成されます。

ダッシュ中にジャンプすると、残像の新規生成とダッシュ姿勢が終了し、通常ジャンプモーションへ移行します。残りのダッシュ時間は空中でも横方向の慣性が維持されます。

### 6. ヒットストップ

攻撃が命中した瞬間や被弾時に、ゲーム内の動きがごく短時間停止します。攻撃の重さと命中感を強調する演出で、ポーズメニューによる一時停止とは異なります。

### 7. ステージクリア

1. オオカミ型・イノシシ型モンスターを突破し、坂道や崖を越えて右へ進む。
2. 森の奥にいる**巨大クマ型ボス**と戦う。
3. ボスを倒したら、さらに**右端へ移動**する。
4. `STAGE CLEAR!` が表示されればクリアです。

## 🌐 GitHub Pagesへの公開方法（リポジトリ管理者向け）

GitHubにログインし、公開するリポジトリへ次のファイルを置きます。

```text
リポジトリ名/
├── index.html   # ゲーム本体
└── README.md    # この説明書（GitHubのトップページに表示）
```

1. GitHubのリポジトリを開き、**`index.html` と `README.md` をルート（最上位）に配置**します。
2. `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` を **Deploy from a branch** にします。
4. `Branch` は **main**、フォルダは **/(root)** を選び、保存します。
5. 公開処理が終わったら、表示されたサイトURLにアクセスします。

公開URLの一般的な形式：

```text
https://＜GitHubユーザー名＞.github.io/＜リポジトリ名＞/
```

> GitHub FreeでGitHub Pagesを利用する場合、通常は**公開（Public）リポジトリ**が必要です。リポジトリを公開すると、アップロードした `index.html` や素材も閲覧・取得可能になります。公開してよい内容か事前に確認してください。

### README.mdを変更するには？

GitHubのリポジトリ直下にある `README.md` を編集してコミットすると、リポジトリのトップページに表示される説明が更新されます。**ゲームのコードを変更せずに、説明書だけ更新可能**です。


### リポジトリで更新履歴を確認するには？

GitHubには、更新内容を見せるための仕組みが複数あります。

| 場所 | 見られる内容 | 主な用途 |
| --- | --- | --- |
| **README.md（本ページ）** | 作者がまとめた変更・追加要素 | 遊ぶ人向けの案内 |
| **Commits（コミット履歴）** | ファイル変更が記録された日時・内容 | 実際の作業履歴の確認 |
| **Releases（リリース）** | バージョン名・更新内容・配布ファイル | 一般プレイヤー向けの更新告知 |
| **Activity（アクティビティ）** | リポジトリの変更活動 | 開発状況の把握 |

`README.md`の履歴は作者が手動で編集する文章であり、コミット履歴から自動生成されたものではありません。正式なバージョンの告知には、今後 **Releases** を併用する方針です。
