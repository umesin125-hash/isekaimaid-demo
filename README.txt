Ver.0.4.3 — タイトル画面追加版

【今回の更新】
・起動直後に専用タイトル画面を表示（夜の森、三日月、魔法陣風デザイン、3人の待機ドット絵）
・「PUSH START」でSTAGE 01「月夜の森」の開始演出→ゲーム操作開始

・Ver.0.4.2のミリア、カナト、アリステア、サイズ70%、敵、MQ、共鳴、ボス、仮想ボタンを維持
・BGM未追加（従来の効果音は維持）

【GitHub Pagesへの更新】
1. このZIP内の index.html を取得してください。
2. リポジトリのルートにある旧 index.html と置き換えてください。
3. main ブランチへコミットし、GitHub Pagesの公開が更新されるのを確認してください。
4. iPhoneのSafariで既存のゲームURLを開き、横画面で確認してください。

【確認項目】
・起動時にタイトルが表示されること
・PUSH START → ステージ名 → 操作可能になること
・画面上の左右移動／JUMP／攻撃／交代／共鳴の操作
・クリア／ゲームオーバー時の再プレイ／タイトルへ戻る
